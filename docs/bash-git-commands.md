## Команды для Bash

- cd - change directory
    - cd \~ - вернуться в корень
    - cd - - вернуться обратно (шаг назад)
    - cd .. - подняться на 1 уровень вверх
    - cd ../.. - подняться на 2 уровня вверх
- ls - list, что лежит по этому пути
- pwd - print working directory
- touch - создать файл
- mkdir - создать директорию
    - mkdir folder1 folder2 folder3 - создание сразу 3 папок
    - mkdir folder/src - создать src в существующей folder
    - mkdir -p folder/src/components - создать структур вложенных папок (их не уществовало)
    - mkdir -p src/{components,assets/{images,icons},utils,styles} docs — сложная структура одной командой: папка docs и src (в assets вложено 2 папки)
- rm file-name — удалить файл
    - rm -rf dir-name — удалить папку -r и все вложенные -f без подтверждения каждого файла

## Команды git

- git add — добавить в стейдж файлы
    - git add . — добавить все файлы и папки в стейдж
- git commit — зафиксировать изменения. откроется текстовый редактор. через пустую строку описание
    - git commit -m "message" — зафиксировать изменения с сообщением -m (заголовок коммита) 
    - git commit -m "message" -m "description"
- git push — отправка измененеий
    - git push -u origin branch-name — отправка ветки в удаленный репозиторий origin и связать локальную ветку с удаленной. делается однажды, затем достаточно git push
    - git push origin --delete branch-name — удаление удалённой ветки
- git fetch — получить обновления, но не внедрять (обратится к серверу по умолчанию, обычно origin)
    - ... --all — скачать для всех удаленных репозиториев
    - ... name-repo — выкачать обновления конкретной репы
    - ... --prune — синхронизирует списки и удалит «мертвые» ветки из вашего локального списка
    - ... -p — тоже, что и --prune
- git branch — работа с веткой
    - ... switch branch-name — перейти на ветку
        - ... ... -c branch-name — создать и перейти на ветку
    - ... -d branch-name — удалить ветку локально. git безопасно проверит, что вмержина
